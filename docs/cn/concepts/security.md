# 安全边界（威胁模型）

从安全评审角度看 v0 **防什么、不防什么** —— token 握手规范，以及诚实划出的边界。

> **状态：** 骨架页 —— 加固工作随实现增量落地。

## 防 / 不防

| 防得住 | 防不住（v0 边界） |
|---|---|
| 静态 token 泄露（token 走 CONNECT 携带） | 网络窃听（无 TLS —— wss 留给 v1；`listen_ws.tls` 占位） |
| token 穷举爆破（服务端只存 SHA-256 摘要 + 常量时间比较） | 动态签发 / 吊销（v1） |
| 管理面暴露（HTTP 只绑 127.0.0.1） | 按 topic 的 authz ACL（v2） |
| 保留名滥用（`$` 前缀） | 恶意客户端除耗尽资源以外的逻辑攻击 |

## Token 握手规范（已冻结）

- CONNECT 帧携带 token；服务端以常量时间比较 `SHA-256(token)` 摘要。
- 失败时：返回通用的 `AUTH_FAILED`（0x0006）并延迟 100 ms，不泄露任何内部信息。
- 复制对端通道使用独立的共享密钥（复制 RPC 绝不复用客户端 token）。
