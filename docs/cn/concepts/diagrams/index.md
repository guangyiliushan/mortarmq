## 四页之间的关系

- **用例与流程** ↔ **关键时序**画的是**同一条**发布/消费链路的两种记法：flowchart 看分支条件与守恒，sequence 看参与者次序。互不包含，两页页首都写清了对方的范围。
- **状态、时限与不变量**收编了对象快照而不是放进「结构」，因为它的载荷是不变量断言表（INV/CM/CB 词表），不是类型布局。
- **结构**把依赖规则写成 CI 强制的 import 断言；类图是同一套规则的类型级表达，并明确以规则表为权威。

## 关于图种的说明

mermaid 没有原生的 UML 用例图、对象图和时序约束图语法，因此这三类分别用 flowchart、类图实例记法和 ASCII 泳道近似。近似会丢信息的地方，页面里附了语义表 —— **那张表才是事实来源**，读文字而不只是看图。
