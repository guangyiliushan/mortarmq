# 核心概念

本章解释 MortarMQ **怎么工作、为什么这么设计**。建议快速开始之后通读一遍，之后在某个行为让你困惑时再回来查单页。

本章全是叙述性内容，不含可复制执行的命令。需要命令去 [使用指南](../guides/index.md)，需要精确的表格和注册表去 [参考手册](../reference/index.md)。

| 页面 | 回答什么问题 |

| [基础概念](./basics.md) | 消息模型 —— topic、分区、组、epoch、credit、quorum、DLQ 各是什么意思 |

| [安全边界](./security.md) | v0 防什么、明确不防什么、token 握手怎么做 |
