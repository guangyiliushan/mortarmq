# MortarMQ

A message queue written in MoonBit, licensed BSD-3-Clause.

The single source of truth for working in this repository is
[CONTRIBUTING.md](./CONTRIBUTING.md). This file only says when to open it —
it restates none of its rules, so the rules have exactly one home.

| You are about to | Open |
|---|---|
| edit a `.mbt` file, its comments, or its file header | [Source standards](./CONTRIBUTING.md) §3 |
| branch, commit, open a pull request, or review one | [Workflow](./CONTRIBUTING.md) §2 |
| run the checks a change must pass | [Quality gates](./CONTRIBUTING.md) §1.2 |
| add a dependency, or bring in any third-party material | [Dependency license policy](./CONTRIBUTING.md) §4.3 |
| decide whether a contribution is allowed at all | [License and compliance](./CONTRIBUTING.md) §4 |
| change anything under `docs/`, or anything a user reads | [Documentation](./CONTRIBUTING.md) §6 |
